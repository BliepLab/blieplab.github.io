Check-in voor alleenwonende burenCheck-in for neighbours who live aloneПроверка самочувствия одиноко живущих соседей

Een kleine, respectvolle voorziening binnen jullie buurt-mesh: geen camera, geen logboek, alleen één dagelijkse controle en een afgesproken zorgkring van 2–3 mensen.A small, respectful provision inside your neighbourhood mesh: no camera, no log, just one daily check and an agreed care circle of 2–3 people.Небольшая и уважительная функция внутри вашей соседской mesh-сети: без камеры и журнала, только одна ежедневная проверка и согласованный круг заботы из 2–3 человек.

Belangrijk: dit is een sociale check, geen medisch hulpmiddel. Het ziet geen val, geen hartstilstand en geen nood zolang iemand wel actief is. Wie medische risico’s heeft, houdt een personenalarmering (alarmknop met meldkamer). Bij nood: bel 112.Important: this is a social check, not a medical device. It does not see a fall, a cardiac arrest or distress as long as someone is active. Anyone with medical risks keeps a personal alarm service (alarm button with a control room). In an emergency: call 112.Важно: это социальная проверка, а не медицинское устройство. Оно не видит падение, остановку сердца или беду, пока человек активен. Тем, у кого есть медицинские риски, нужна служба персональной тревожной кнопки (с диспетчерским центром). В экстренной ситуации: звоните 112.

Het idee in één minuutThe idea in one minuteИдея за одну минуту

  • De bewoner blijft zelfstandig. Niemand kijkt mee.The resident stays independent. Nobody watches.Жилец остаётся самостоятельным. Никто не наблюдает.
  • Een kleine sensor merkt alleen dat er leven in huis is en stuurt daar niets over.A small sensor only notices that there is life in the home and sends nothing about it.Небольшой датчик лишь замечает, что в доме есть жизнь, и ничего об этом не отправляет.
  • Eén keer per dag, op een afgesproken tijdstip, controleert het apparaatje of er activiteit was.Once a day, at an agreed time, the device checks whether there was activity.Раз в день в согласованное время устройство проверяет, была ли активность.
  • Was er niets, dan piept het eerst zacht bij de bewoner zelf. Een druk op de knop, of gewoon even de kamer in lopen, is genoeg.If there was nothing, it first beeps softly at the resident. Pressing the button, or just walking into the room, is enough.Если активности не было, устройство сначала тихо пищит у самого жильца. Достаточно нажать кнопку или просто войти в комнату.
  • Pas als er na 30 minuten nog niets is, krijgt de zorgkring één kort bericht. Een mens belt of loopt langs.Only if there is still nothing after 30 minutes does the care circle get one short message. A person calls or walks over.Только если через 30 минут всё ещё ничего нет, круг заботы получает одно короткое сообщение. Человек звонит или заходит.

PrincipesPrinciplesПринципы

  • Toestemming eerst. Zonder een duidelijk ja van de bewoner (en liefst van de familie) gaat er niets aan.Consent first. Nothing is switched on without a clear yes from the resident (and preferably the family).Сначала согласие. Без ясного «да» жильца (и желательно семьи) ничего не включается.
  • De bewoner houdt de regie. Een pauzeschakelaar “ik ben weg”, altijd te stoppen, en de bewoner hoort en ziet wat het apparaat doet.The resident stays in control. An “I’m away” pause switch, can stop at any time, and the resident hears and sees what the device does.Жилец остаётся хозяином. Переключатель паузы «меня нет», можно остановить в любой момент, и жилец слышит и видит, что делает устройство.
  • Zo min mogelijk gegevens. Geen camera, geen beelden, geen bewegingslogboek, alleen een huisnummer in het bericht.As little data as possible. No camera, no images, no movement log, only a house number in the message.Минимум данных. Никаких камер, изображений и журнала движений, в сообщении только номер дома.
  • Een mens beslist. Het systeem belt nooit zelf 112; buren bellen of lopen langs.A human decides. The system never calls 112 by itself; neighbours phone or walk over.Решает человек. Система сама никогда не вызывает 112; соседи звонят или заходят.
  • Geen verrassingen. Elke maand een testbericht, elk jaar een gesprek of het nog past.No surprises. A test message every month, a conversation every year on whether it still fits.Без сюрпризов. Каждый месяц тестовое сообщение, каждый год разговор о том, подходит ли это ещё.
  • Stilte is ook een signaal. Elke dag komt een kort “OK”. Blijft dat uit, dan kijkt de zorgkring even. Zo valt ook een kapot apparaat op.Silence is a signal too. A short “OK” arrives every day. If it does not, the care circle takes a look. That is how a broken device gets noticed as well.Тишина тоже сигнал. Каждый день приходит короткое «OK». Если его нет, круг заботы проверяет. Так замечают и сломанное устройство.

Zo werkt een dagHow a day worksКак проходит день

  1. 07:00–10:30: de sensor ziet beweging of aanwezigheid in de kamer. Het apparaat onthoudt alleen “vandaag is er activiteit geweest”.07:00–10:30: the sensor sees movement or presence in the room. The device only remembers “there was activity today”.07:00–10:30: датчик видит движение или присутствие в комнате. Устройство запоминает только «сегодня активность была».
  2. 10:30, wel activiteit: één kort bericht “Check-in OK nr 12” naar de zorgkring (dat kun je uitzetten).10:30, activity seen: one short message “Check-in OK nr 12” to the care circle (you can switch this off).10:30, активность была: одно короткое сообщение «Check-in OK nr 12» кругу заботы (это можно отключить).
  3. 10:30, geen activiteit: het apparaat piept elke minuut zacht en de led knippert. Druk op de knop of loop de kamer in: klaar, er wordt niets verstuurd.10:30, no activity: the device beeps softly every minute and the LED blinks. Press the button or walk into the room: done, nothing is sent.10:30, активности нет: устройство тихо пищит каждую минуту и мигает светодиод. Нажмите кнопку или войдите в комнату: готово, ничего не отправляется.
  4. 11:00, nog steeds niets: alarmbericht naar de zorgkring, daarna maximaal 2 herhalingen met 30 minuten ertussen.11:00, still nothing: alert message to the care circle, then at most 2 repeats 30 minutes apart.11:00, всё ещё ничего: сообщение-тревога кругу заботы, затем максимум 2 повтора с интервалом 30 минут.
  5. Later weer activiteit: bericht “weer activiteit, alles in orde”, zodat niemand zich nog zorgen maakt.Activity again later: a message “active again, all fine”, so nobody keeps worrying.Позже снова активность: сообщение «снова активность, всё в порядке», чтобы никто больше не волновался.
  6. Schakelaar “ik ben weg”: pauze zonder berichten. Weer uit: gewoon doorgaan.“I’m away” switch: pause with no messages. Switch it off again: carry on as normal.Переключатель «меня нет»: пауза без сообщений. Выключили: всё продолжается как обычно.

Het bericht is bewust kort: ALARM check-in gemist nr 12: nog geen activiteit vandaag. Bel of loop even langs.The message is deliberately short and is in Dutch in the code: ALARM check-in gemist nr 12: nog geen activiteit vandaag. Bel of loop even langs. (“ALARM check-in missed nr 12: no activity yet today. Call or walk over.”). Change it to your language.Сообщение намеренно короткое, в коде оно на нидерландском: ALARM check-in gemist nr 12: nog geen activiteit vandaag. Bel of loop even langs. («ALARM: check-in пропущен, дом 12: сегодня ещё нет активности. Позвоните или зайдите»). Замените его на нужный язык.

Zorgkring en afsprakenCare circle and agreementsКруг заботы и договорённости

De techniek is het makkelijke deel. Het echte project is de afspraak tussen mensen.The technology is the easy part. The real project is the agreement between people.Техника — лёгкая часть. Настоящий проект — это договорённость между людьми.

  • Bewoner: beslist, kan pauzeren en stoppen wanneer hij of zij wil.Resident: decides, can pause and stop whenever they like.Жилец: решает, может поставить на паузу и остановить, когда захочет.
  • Zorgkring (2–3 mensen, liefst een familielid en buren): ontvangt het alarm, belt of loopt langs.Care circle (2–3 people, preferably a relative and neighbours): receives the alert, phones or walks over.Круг заботы (2–3 человека, лучше родственник и соседи): получает сигнал, звонит или заходит.
  • Beheerder: houdt het apparaat in orde (test, klok, batterij) en leest geen privézaken mee.Keeper: keeps the device in order (test, clock, battery) and does not read private matters.Хранитель: следит за исправностью устройства (тест, часы, батарейка) и не читает личное.

Als een alarm binnenkomt:When an alert arrives:Когда приходит сигнал:

  1. Bel de bewoner, twee keer.Phone the resident, twice.Позвоните жильцу, два раза.
  2. Geen antwoord? Loop langs en bel aan.No answer? Walk over and ring the bell.Нет ответа? Зайдите и позвоните в дверь.
  3. Geen reactie, of iets wat je ongerust maakt? Bel 112. Heb je een sleutel, gebruik die dan alleen zoals afgesproken.No response, or something that worries you? Call 112. If you have a key, use it only as agreed.Нет реакции или что-то тревожит? Звоните 112. Если у вас есть ключ, используйте его только так, как договорились.
  4. Schrijf in de kring wie gaat (“ik ga”), zodat niet iedereen tegelijk komt en niet niemand.Write in the circle who is going (“I’ll go”), so not everyone arrives at once and not nobody.Напишите в круге, кто идёт («я иду»), чтобы не пришли все сразу и не не пришёл никто.
  5. Meld het weer als alles in orde is.Report back when all is well.Сообщите, когда всё в порядке.

Checklist vóór de start:Checklist before you start:Чек-лист перед запуском:

  • Je hebt met de bewoner gepraat, in alle rust. Het is geen verrassing en geen verplichting.You talked to the resident, calmly. It is no surprise and no obligation.Вы поговорили с жильцом, спокойно. Это не сюрприз и не обязанность.
  • De zorgkring is bekend en iedereen heeft ja gezegd.The care circle is known and everyone said yes.Круг заботы известен, и все согласились.
  • Het is duidelijk wie een sleutel heeft, of dat er geen sleutel is.It is clear who has a key, or that nobody does.Ясно, у кого есть ключ, или что ключа ни у кого нет.
  • De tijden zijn gekozen (venster, controle) en passen bij het ritme van de bewoner.The times are chosen (window, check) and fit the resident’s rhythm.Время выбрано (окно, проверка) и подходит ритму жильца.
  • De bewoner weet hoe je pauzeert en stopt.The resident knows how to pause and stop.Жилец знает, как поставить на паузу и остановить.
  • Er staat een evaluatiedatum (binnen 3 maanden, daarna jaarlijks).An evaluation date is set (within 3 months, then yearly).Назначена дата оценки (в течение 3 месяцев, затем ежегодно).

Meshtastic instellenSetting up MeshtasticНастройка Meshtastic

  1. Flash de node in de browser en kies regio EU_868.Flash the node in the browser and choose region EU_868.Прошейте ноду в браузере и выберите регион EU_868.
  2. Maak voor deze zorgkring een eigen privékanaal (bijvoorbeeld “zorg-12”, met een eigen willekeurige sleutel) en zet het als eerste kanaal van deze node. Voeg hetzelfde kanaal (QR-code) alleen toe aan de telefoons of nodes van de zorgkring.Create a separate private channel for this care circle (for example “zorg-12”, with its own random key) and set it as this node’s first channel. Add the same channel (QR code) only to the phones or nodes of the care circle.Создайте для этого круга заботы отдельный приватный канал (например, «zorg-12» с собственным случайным ключом) и сделайте его первым каналом этой ноды. Добавьте тот же канал (QR-код) только в телефоны или ноды круга заботы.
  3. Zet het delen van de locatie uit en geef de node het huisnummer als naam.Turn off location sharing and name the node after the house number.Отключите передачу местоположения и назовите ноду номером дома.
  4. Zet de Serial-module aan: modus TEXTMSG, baudrate zoals in de schets (9600), RX-pin zoals je bedraad hebt. Menu-namen verschillen per firmwareversie: volg de actuele Meshtastic-documentatie voor de Serial-module.Enable the Serial module: mode TEXTMSG, baud rate as in the sketch (9600), RX pin as you wired it. Menu names differ per firmware version: follow the current Meshtastic documentation for the Serial module.Включите модуль Serial: режим TEXTMSG, скорость как в скетче (9600), RX-пин как вы подключили. Названия меню зависят от версии прошивки: следуйте актуальной документации Meshtastic по модулю Serial.
  5. Test: houd de knop 3 seconden ingedrukt. De zorgkring moet “TEST check-in nr 12” ontvangen, en niemand anders.Test: hold the button for 3 seconds. The care circle must receive “TEST check-in nr 12”, and nobody else.Тест: удерживайте кнопку 3 секунды. Круг заботы должен получить «TEST check-in nr 12», и больше никто.
  6. Test het bereik: het bericht moet ook aankomen bij iemand uit de zorgkring die een paar straten verderop is. Komt het niet door, controleer dan of de gedeelde router pakketten van dit kanaal doorgeeft. Zo niet, dan kan het kanaal ook aan de router worden toegevoegd, maar wie de router beheert kan dan de berichten lezen: spreek af wie dat is.Test the range: the message must also arrive for someone in the care circle a few streets away. If it does not get through, check that the shared router relays packets of this channel. If not, the channel can also be added to the router, but whoever manages the router can then read the messages: agree who that is.Проверьте дальность: сообщение должно дойти и до члена круга заботы, находящегося в нескольких улицах. Если не доходит, проверьте, передаёт ли общий роутер пакеты этого канала. Если нет, канал можно добавить и на роутер, но тогда его хранитель сможет читать сообщения: договоритесь, кто это.

// checkin.ino - neighbour check-in node (ESP32-C3 SuperMini)
// Reads a presence sensor, decides with checkin_core.h and sends a short text
// to a Meshtastic node over a serial cable (Meshtastic "Serial module", TEXTMSG mode).
//
// Libraries: "RTClib" by Adafruit. Board: ESP32C3 Dev Module (USB CDC on boot: enabled).
// Put checkin_core.h in the same folder as this file.
//
// IMPORTANT: this sketch was written for real hardware but has not been tested on it yet.
// Test every part with the checklist on the guide page before you rely on it.

#include <Wire.h>
#include <RTClib.h>
#include "checkin_core.h"

// ---------- settings you change ----------
#define HOUSE "12"                  // house number used in the messages
#define SERIAL_BAUD 9600            // must match the Meshtastic Serial module setting
checkin::Config cfg;                // times: see checkin_core.h (07:00, 10:30, 30 min)

// ---------- pins (ESP32-C3 SuperMini) ----------
const int PIN_PRESENCE = 0;   // LD2410C OUT (HIGH = presence)
const int PIN_BUTTON   = 1;   // big button to GND
const int PIN_AWAY     = 3;   // "I'm away" switch to GND (closed = away)
const int PIN_BUZZER   = 4;   // active buzzer (use a transistor if it draws more than 20 mA)
const int PIN_LED      = 5;   // LED + 330 ohm to GND
const int PIN_SDA      = 6;   // DS3231
const int PIN_SCL      = 7;
const int PIN_MESH_TX  = 10;  // to the RX pin of the Meshtastic node (common GND!)

// ---------- messages (Dutch; change to your language) ----------
const char MSG_OK[]        = "Check-in OK nr " HOUSE;
const char MSG_ALERT[]     = "ALARM check-in gemist nr " HOUSE ": nog geen activiteit vandaag. Bel of loop even langs.";
const char MSG_REPEAT[]    = "HERHALING check-in gemist nr " HOUSE ". Bel of loop even langs.";
const char MSG_RECOVERED[] = "Check-in nr " HOUSE ": weer activiteit, alles in orde.";
const char MSG_TEST[]      = "TEST check-in nr " HOUSE;

RTC_DS3231 rtc;
checkin::State state;
uint32_t lastTick = 0, lastBeep = 0, buttonDownAt = 0;
uint8_t presenceStreak = 0;
bool buttonWas = false;
bool buttonEvent = false;

void sendText(const char* text) {
  Serial1.println(text);
  Serial.println(text);  // also visible on the USB serial monitor
}

void beep(uint16_t ms) {
  digitalWrite(PIN_BUZZER, HIGH);
  delay(ms);
  digitalWrite(PIN_BUZZER, LOW);
}

void setup() {
  pinMode(PIN_PRESENCE, INPUT);
  pinMode(PIN_BUTTON, INPUT_PULLUP);
  pinMode(PIN_AWAY, INPUT_PULLUP);
  pinMode(PIN_BUZZER, OUTPUT);
  pinMode(PIN_LED, OUTPUT);
  Serial.begin(115200);
  Serial1.begin(SERIAL_BAUD, SERIAL_8N1, -1, PIN_MESH_TX);  // transmit only
  Wire.begin(PIN_SDA, PIN_SCL);
  if (!rtc.begin()) {
    while (true) { digitalWrite(PIN_LED, !digitalRead(PIN_LED)); delay(100); }  // fast blink: no RTC
  }
  if (rtc.lostPower()) {
    // First start: take the time of compiling. Flash the board right after compiling,
    // or set the time another way, otherwise the clock is wrong.
    rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
  }
  beep(100);
}

void loop() {
  // button: short press = "I'm OK", long press (3 s) = send a test message
  bool down = digitalRead(PIN_BUTTON) == LOW;
  if (down && !buttonWas) buttonDownAt = millis();
  if (!down && buttonWas) {
    if (millis() - buttonDownAt >= 3000) { sendText(MSG_TEST); beep(300); }
    else buttonEvent = true;
  }
  buttonWas = down;

  // once per second: sensor, clock, decision
  if (millis() - lastTick >= 1000) {
    lastTick = millis();
    presenceStreak = (digitalRead(PIN_PRESENCE) == HIGH) ? min<int>(presenceStreak + 1, 10) : 0;
    DateTime now = rtc.now();
    checkin::Input in;
    in.minuteOfDay = now.hour() * 60 + now.minute();
    in.activity = presenceStreak >= 2 || buttonEvent;  // 2 s of presence filters out glitches
    in.away = digitalRead(PIN_AWAY) == LOW;
    buttonEvent = false;

    switch (checkin::step(state, cfg, in)) {
      case checkin::EV_SEND_OK:           sendText(MSG_OK); break;
      case checkin::EV_SEND_ALERT:        sendText(MSG_ALERT); break;
      case checkin::EV_SEND_ALERT_REPEAT: sendText(MSG_REPEAT); break;
      case checkin::EV_SEND_RECOVERED:    sendText(MSG_RECOVERED); break;
      default: break;
    }

    // status LED: steady = fine, slow blink = prompting, fast blink = alert sent, off = away
    uint8_t sec = now.second();
    switch (state.phase) {
      case checkin::PROMPTING: digitalWrite(PIN_LED, sec % 2); break;
      case checkin::ALERTED:   digitalWrite(PIN_LED, (millis() / 250) % 2); break;
      case checkin::PAUSED:    digitalWrite(PIN_LED, LOW); break;
      default:                 digitalWrite(PIN_LED, sec % 10 == 0 ? HIGH : LOW); break;  // short flash every 10 s
    }
    // gentle beep once a minute while prompting
    if (state.phase == checkin::PROMPTING && sec == 0) beep(150);
  }
}
checkin_core.h
// checkin_core.h - pure decision logic for the neighbour check-in node.
// No Arduino dependencies, so it can be tested on a normal computer.
// Time is handled in minutes since midnight (0..1439), local time.
#pragma once
#include <stdint.h>

namespace checkin {

struct Config {
  uint16_t windowStartMin = 7 * 60;       // activity counts from 07:00
  uint16_t deadlineMin    = 10 * 60 + 30; // first check at 10:30
  uint16_t graceMin       = 30;           // beeping time before an alert is sent
  uint8_t  alertRepeats   = 2;            // extra alert messages after the first
  uint16_t repeatEveryMin = 30;           // minutes between alert messages
  bool     dailyOk        = true;         // send a short "OK" every day
};

enum Phase : uint8_t {
  WAITING,    // window open or not yet started, waiting for the deadline
  OK_DONE,    // today's check passed (or was skipped)
  PROMPTING,  // no activity at the deadline: beep and wait for the resident
  ALERTED,    // grace time over: care circle has been messaged
  PAUSED      // "I'm away" switch is on
};

enum Event : uint8_t {
  EV_NONE,
  EV_SEND_OK,
  EV_SEND_ALERT,
  EV_SEND_ALERT_REPEAT,
  EV_SEND_RECOVERED
};

struct Input {
  uint16_t minuteOfDay;  // 0..1439
  bool activity;         // presence detected or button pressed right now
  bool away;             // "I'm away" switch is on
};

struct State {
  bool     init = false;
  Phase    phase = WAITING;
  bool     activity = false;   // activity seen inside today's window
  bool     awayPrev = false;
  uint16_t prev = 0;           // previous minuteOfDay
  uint16_t promptStart = 0;
  uint16_t lastAlert = 0;
  uint8_t  alertsSent = 0;
};

// minutes elapsed from 'from' to 'to', across midnight
inline uint16_t elapsed(uint16_t from, uint16_t to) {
  return (uint16_t)((to + 1440u - from) % 1440u);
}

// true when the clock moved over 'mark' between 'prev' and 'now'
inline bool crossed(uint16_t prev, uint16_t now, uint16_t mark) {
  if (prev == now) return false;
  if (prev < now) return prev < mark && now >= mark;
  return mark > prev || mark <= now;  // wrapped over midnight
}

inline bool inWindow(const Config& c, uint16_t now) {
  return now >= c.windowStartMin && now < c.deadlineMin;
}

// Call this every second or so. Returns an event when a message must be sent.
inline Event step(State& s, const Config& c, const Input& in) {
  Event ev = EV_NONE;
  const uint16_t now = in.minuteOfDay;

  if (!s.init) {
    s.init = true;
    s.prev = now;
    s.awayPrev = in.away;
    s.activity = false;
    s.phase = in.away ? PAUSED : (now >= c.deadlineMin ? OK_DONE : WAITING);
  }

  // "I'm away" switch
  if (in.away) {
    s.phase = PAUSED;
    s.awayPrev = true;
    s.prev = now;
    return EV_NONE;
  }
  if (s.awayPrev) {  // switch just turned off: resident is back
    s.awayPrev = false;
    s.activity = true;
    s.alertsSent = 0;
    s.phase = (now >= c.deadlineMin) ? OK_DONE : WAITING;
  }

  // new day: reset when the window start is passed
  if (crossed(s.prev, now, c.windowStartMin)) {
    s.phase = WAITING;
    s.activity = false;
    s.alertsSent = 0;
  }
  s.prev = now;

  // activity
  if (in.activity) {
    if (s.phase == WAITING && inWindow(c, now)) {
      s.activity = true;
    } else if (s.phase == PROMPTING) {
      s.activity = true;
      s.phase = OK_DONE;
    } else if (s.phase == ALERTED) {
      s.activity = true;
      s.phase = OK_DONE;
      s.alertsSent = 0;
      return EV_SEND_RECOVERED;
    }
  }

  // deadline reached
  if (s.phase == WAITING && now >= c.deadlineMin) {
    if (s.activity) {
      s.phase = OK_DONE;
      if (c.dailyOk) ev = EV_SEND_OK;
    } else {
      s.phase = PROMPTING;
      s.promptStart = now;
    }
    return ev;
  }

  // beeping time over
  if (s.phase == PROMPTING && elapsed(s.promptStart, now) >= c.graceMin) {
    s.phase = ALERTED;
    s.alertsSent = 1;
    s.lastAlert = now;
    return EV_SEND_ALERT;
  }

  // repeat alert a limited number of times
  if (s.phase == ALERTED && s.alertsSent <= c.alertRepeats &&
      elapsed(s.lastAlert, now) >= c.repeatEveryMin) {
    s.alertsSent++;
    s.lastAlert = now;
    return EV_SEND_ALERT_REPEAT;
  }
  return ev;
}

}  // namespace checkin
